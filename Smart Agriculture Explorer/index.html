ℹ️ About AgroGuide

AgroGuide is a Smart Agriculture Information & Crop Explorer built for a Web Programming Lab project. It helps users explore crops, soil types, irrigation needs, and seasonal planting information through a clean, dashboard-style interface.

Crop data is loaded dynamically from a JSON file using AJAX (Fetch API), then rendered into the page through DOM manipulation — with live search and filtering by category, soil, water requirement, and season.
